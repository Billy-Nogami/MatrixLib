# ListLib

Учебная библиотека на C для работы с односвязными списками.

## Описание

Проект представляет собой модульную библиотеку на языке C для выполнения базовых операций над списками чисел. Библиотека разработана в стиле проекта с матрицами и делает акцент на:

- разбиение программы на отдельные модули
- использование динамической памяти
- работу со структурами и указателями
- обработку ошибок через коды возврата
- тестирование реализованных функций

Список хранится в структуре `List`:

```c
typedef struct ListNode {
    double value;
    struct ListNode *next;
} ListNode;

typedef struct {
    ListNode *head;
    ListNode *tail;
    size_t size;
} List;
```

Каждый элемент списка хранится в отдельном узле. Структура списка содержит указатели на начало и конец, а также количество элементов.

## Реализованные возможности

- создание и освобождение списка
- добавление элементов в начало и конец
- удаление элементов из начала и конца
- вставка и удаление по индексу
- чтение и запись элементов по индексу
- заполнение списка значением
- копирование списка
- поиск значения
- поэлементное сложение и вычитание списков
- умножение элементов списка на число
- объединение списков
- разворот списка

## Функции библиотеки

- `list_create` — инициализация пустого списка
- `list_free` — освобождение памяти и очистка структуры
- `list_copy` — создание копии списка
- `list_push_back` — добавление элемента в конец
- `list_push_front` — добавление элемента в начало
- `list_pop_back` — удаление элемента из конца
- `list_pop_front` — удаление элемента из начала
- `list_insert` — вставка элемента по индексу
- `list_remove_at` — удаление элемента по индексу
- `list_get` — чтение элемента по индексу
- `list_set` — запись элемента по индексу
- `list_fill` — заполнение всех элементов одинаковым значением
- `list_find` — поиск индекса первого подходящего значения
- `list_add` — поэлементное сложение списков одинаковой длины
- `list_sub` — поэлементное вычитание списков одинаковой длины
- `list_scalar_mul` — умножение всех элементов на число
- `list_concat` — объединение двух списков
- `list_reverse` — разворот списка

## Обработка ошибок

Большинство функций возвращают значение типа `ListStatus`. Используются следующие коды:

- `LIST_SUCCESS` — операция выполнена успешно
- `LIST_ERROR_NULL` — передан `NULL`
- `LIST_ERROR_ALLOC` — ошибка выделения памяти
- `LIST_ERROR_BOUNDS` — выход за границы списка
- `LIST_ERROR_SIZE` — несовместимые размеры списков
- `LIST_ERROR_EMPTY` — операция невозможна для пустого списка
- `LIST_ERROR_NOT_FOUND` — значение не найдено

## Структура проекта

- `include/list.h` — описание структур `List`, `ListNode`, кодов ошибок и интерфейса библиотеки
- `src/list_memory.c` — создание, освобождение и копирование списков
- `src/list_access.c` — добавление, удаление, доступ к элементам, заполнение и поиск
- `src/list_basic.c` — базовые арифметические операции
- `src/list_advanced.c` — объединение и разворот списков
- `tests/test_list.c` — набор тестов для проверки работы библиотеки
- `Makefile` — сборка проекта и запуск тестов

## Пример использования

```c
#include <stdio.h>
#include "list.h"

int main(void) {
    List left = {0};
    List right = {0};
    List result = {0};

    if (list_create(&left) != LIST_SUCCESS) {
        return 1;
    }

    if (list_create(&right) != LIST_SUCCESS) {
        list_free(&left);
        return 1;
    }

    list_push_back(&left, 1.0);
    list_push_back(&left, 2.0);
    list_push_back(&right, 3.0);
    list_push_back(&right, 4.0);

    if (list_add(&left, &right, &result) == LIST_SUCCESS) {
        double value = 0.0;
        list_get(&result, 1, &value);
        printf("result[1] = %.2f\n", value);
    }

    list_free(&left);
    list_free(&right);
    list_free(&result);
    return 0;
}
```
